# Personal website

A small static HTML/CSS site. Open `index.html` locally or serve the folder with `python -m http.server 8000`.

Pages: `index.html`, `about.html`, `research.html`, `projects.html`, `blog.html`, and `cv.html`.

Existing blog posts are in `blog/`. Add new posts as HTML files and link them from `blog.html` and (optionally) `index.html`. A Markdown publishing workflow can be added later.

The dedicated Teaching page has been removed; teaching history remains in the CV.

This is a first-pass editorial and layout refresh. Review copy, links, and publication details before publishing.
